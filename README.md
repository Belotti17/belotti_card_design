# Digital Business Card

Carte de visite digitale interactive et moderne conçue pour présenter mon profil de **Full-Stack Developer & UI/UX Designer** à travers une expérience web unique, élégante et responsive.

## Présentation

Ce projet est une carte de visite professionnelle en **HTML, CSS et JavaScript vanilla**.

L'objectif est de présenter rapidement :

* Mon identité professionnelle
* Mes compétences
* Mon domaine d'expertise
* Mes réseaux sociaux
* Mes coordonnées
* Mon profil de développeur et designer

Le design s'inspire des interfaces éditoriales modernes et des produits digitaux premium, avec une attention particulière portée aux animations, à la typographie et aux détails visuels.

## Technologies

* HTML5
* CSS3
* JavaScript Vanilla
* Font Awesome

Aucun framework ou bibliothèque JavaScript n'est utilisé.

## Fonctionnalités

* Loader animé au chargement de la page
* Animations d'apparition des contenus
* Texte animé
* Animations CSS infinies
* Curseur personnalisé sur desktop
* Effet parallaxe avec la souris
* Effets hover interactifs
* Animations au scroll
* Responsive design
* Support de `prefers-reduced-motion`
* Icônes Font Awesome
* Liens vers les réseaux sociaux
* Section de contact
* Structure facilement personnalisable



## Personnalisation

Les informations personnelles peuvent être modifiées directement dans `index.html`.

Les principaux éléments à remplacer sont :

```text
[MON NOM]
[EMAIL]
[TÉLÉPHONE]
[LOCALISATION]
[LIENS RÉSEAUX SOCIAUX]
```

La photo et le logo peuvent être ajoutés dans :

```text
assets/images/
```

## Lancer le projet

Aucune installation n'est nécessaire.

Il suffit d'ouvrir :

```text
index.html
```

directement dans un navigateur.

Pour une meilleure expérience de développement, le projet peut également être lancé avec l'extension **Live Server** de VS Code.

Créer une identité digitale professionnelle qui combine :
